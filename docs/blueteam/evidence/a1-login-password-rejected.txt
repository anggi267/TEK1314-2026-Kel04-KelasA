BUKTI A.1 — percobaan login SSH dengan password DITOLAK
Target Node: Ubuntu 26.04 LTS, hostname kabita, 192.168.56.101 (ssh port 2222)
Diambil dari host penguji (klien SSH di laptop), sesi 2026-10-23
========================================================================

1) Login dengan metode password (publickey dimatikan di sisi klien)
$ ssh -p 2222 -o PubkeyAuthentication=no -o PreferredAuthentications=password -o BatchMode=yes iotadmin@192.168.56.101 true
iotadmin@192.168.56.101: Permission denied (publickey).
[exit code 255]

2) Metode autentikasi yang masih diterima server (mode verbose)
$ ssh -vv -p 2222 -o PubkeyAuthentication=no -o PreferredAuthentications=password -o BatchMode=yes iotadmin@192.168.56.101 true 2>&1 | grep -E 'Authentications that can continue|Permission denied'
debug1: Authentications that can continue: publickey
iotadmin@192.168.56.101: Permission denied (publickey).

3) Login sebagai root juga ditolak (PermitRootLogin no)
$ ssh -p 2222 -o BatchMode=yes -o PreferredAuthentications=password root@192.168.56.101 true
root@192.168.56.101: Permission denied (publickey).

4) Ringkasan config efektif di sisi server (sshd -T, bukan file config mentah)
port 2222
usepam yes
permitrootlogin no
pubkeyauthentication yes
passwordauthentication no
kbdinteractiveauthentication no
