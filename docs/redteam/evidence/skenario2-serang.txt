KESIMPULAN
------------------------------------------------------------------------------
Hydra tidak pernah sampai satu percobaan pun karena server menolak metode password
("does not support password authentication (method reply 4)") — selama PasswordAuthentication=no,
password guessing lewat SSH tidak mungkin berhasil. Delapan percobaan login dengan akun tak dikenal tetap
tercatat sebagai kegagalan dan fail2ban memblokir IP penyerang setelah ambang terlampaui (Total failed 8,
maxretry 5). Efeknya nyata: tcp/2222 menjadi Connection refused, sedangkan tcp/80 dan tcp/1883 tetap normal.
Nilai temuan: brute force tidak efektif, tetapi siapa pun dapat memicu blokir IP sendiri (atau IP pengguna
sah) dengan 6-8 koneksi gagal selama 600 detik.
