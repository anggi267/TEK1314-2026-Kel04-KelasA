------------------------------------------------------------------------------
KESIMPULAN
------------------------------------------------------------------------------
Selama kelima skenario, Security Onion tidak menghasilkan satu pun alert: Squert menunjukkan 0 event pada
seluruh rentang 4 November 2026 tanpa filter, sehingga hasilnya bukan karena penyaringan tampilan.
Penyebab yang terlihat di sensor: berkas alert Snort (unified2) terakhir berukuran 0 byte dan bertanggal
19 Juni 2020, tidak ada satu pun berkas unified2 baru sejak 1 November 2026, dan proses snort tidak lagi
dijumpai saat pemeriksaan (hanya barnyard2 yang berjalan). Karena unified2 tidak pernah ditulis, barnyard2
tidak memiliki apa pun untuk dimasukkan ke basis data Sguil, dan Squert tetap kosong.

Konsekuensi: pada kondisi ini seluruh aktivitas penyerang di segmen 192.168.4.0/24 tidak terdeteksi oleh
IDS/NSM. Ini dicatat apa adanya sebagai temuan, bukan sebagai bukti bahwa serangan tidak berbahaya.
Perbaikan berada di ranah Blue Team (pastikan snort berjalan dengan -i eth0, arahkan output unified2 ke
/nsm/sensor_data/seconion-eth0/snort-1/ dengan path absolut, lalu jalankan barnyard2 untuk sensor tersebut).
