RANGKUMAN HASIL
  Uji manual payload pada segmen path id — keempat payload dijawab HTTP 400:
    1 OR 1=1 (1%20OR%201%3D1)      -> 400 Bad Request
    tanda kutip tunggal (1%27)     -> 400 Bad Request
    1 UNION SELECT 1,2,3,4         -> 400 Bad Request
    1;SELECT pg_sleep(2)           -> 400 Bad Request
  sqlmap (perintah panduan apa adanya): 2.313 permintaan ber-UA "sqlmap/1.10.9#stable".
    Distribusi respons di access log nginx: 2208 x 400, 93 x 404, 12 x 200.
    12 respons 200 itu bukan bukti lolos: semuanya URL bersih yang ditambahi QUERY STRING
    karangan sqlmap (mis. ?tyqb=2266 AND 1=1 UNION ...) yang diabaikan aplikasi
    (Go hanya membaca segmen path); body-nya sama dengan baseline (599 byte).
  sqlmap menyimpulkan: "all tested parameters do not appear to be injectable".
  Uji ulang dengan penanda titik injeksi eksplisit (1*/riwayat, --level=2 --risk=1): hasil sama,
  501 x HTTP 400, tidak ada parameter yang injectable.
  Root cause dibaca dari kode: segmen path divalidasi strconv.Atoi (main.go kambingSubRouter)
  dan query-nya parameterized: db.Query("... WHERE kambing_id = $1 ...", id).
  log_statement PostgreSQL tidak merekam satu pun query ber-payload dalam jendela uji;
  permintaan ditolak sebelum menyentuh database.
